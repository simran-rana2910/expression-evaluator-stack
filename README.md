# Expression Evaluator (Stack)

## 📌 Description
This project evaluates mathematical expressions using stack.

## 🚀 Features
- Infix to Postfix conversion
- Postfix evaluation
- Handles brackets and operator precedence
- Step-by-step output

## 🧮 Example
Input: (3 + 4) * 2  
Postfix: 3 4 + 2 *  
Output: 14

- Python
